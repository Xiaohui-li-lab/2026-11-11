# Figures

This directory contains the manuscript figures generated by the scripts in
`code/`.

- `figure1_decomposition_assembly.pdf` / `.png`: Quantum decomposition-assembly model.
- `figure2_cardio_photonic_hypothesis.pdf` / `.png`: Cardio-photonic hypothesis schematic.
- `figure3_capacity_benchmark.pdf` / `.png`: Capacity benchmark and fidelity simulation.

Run `python code/generate_all_figures.py` from the repository root to regenerate
all figures.
